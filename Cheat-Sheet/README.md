> **Source:** Nathan Eric Dickman, *Using Questions to Think* (Bloomsbury, 2021)

## The thesis in one line

**To understand a complete thought is to understand it as an answer to a question.** Questions come first (the **hermeneutic priority of questions**), and a culture that only trades answers (an **age of answers**) stops thinking.

---

## The three definitions

| Domain | Definition | Particles | Bond | Unit |
|---|---|---|---|---|
| **Thinking** | Combining or separating subjects and predicates | subject + predicate | copula ("to be") | complete thought |
| **Reasoning** | Combining or separating complete thoughts through inference | premise + conclusion | inference | argument |
| **Dialogue** | Combining or separating arguments | thesis + antithesis (→ synthesis) | dialectics | dialogue / fusion of horizons |

**Questioning turns what we perceive into what we understand:**

```
sentence      ──question──▶  complete thought
exposition    ──question──▶  argument
conversation  ──question──▶  dialogue
```

**What you get without genuine questions:** dogmatic thought → instrumental reasoning → dictatorial monologue.

## The twelve orientations of questioning

The sample prompts are our own phrasings, not quotes from the book.

| Domain | Orientation | What's held fixed → what's opened | Sample prompt |
|---|---|---|---|
| **Thinking** (Ch. 3) | Predicate (predicament)-centered | subject fixed → predicate open | "Where are the keys?" |
| | Subject-centered | predicate fixed → subject open | "What's on the counter?" |
| | Copula-centered | whole thought given → its grounds open | "Is that really so? How do you know?" |
| | Questioning-centered | the questioner's own way of asking | "Why am I asking it this way?" |
| **Reasoning** (Ch. 6) | Conclusion-centered | premise given → conclusions open | "And?" |
| | Premise-centered | conclusion given → premises open | "But why?" |
| | Inference-centered | the link between them | "Does that actually follow?" |
| | Rationality-centered | reason and us as reasoners | "What counts as a good reason here?" |
| **Dialogue** (Ch. 9) | Antithesis-centered | thesis given → negations open | "What's the strongest objection?" |
| | Thesis-centered | the starting claim, rebuilt as a hypo-thesis | "What exactly was the original claim?" |
| | Synthesis-centered | anticipated completion | "Where does this leave us?" |
| | Dialectics-centered | how the dialogue itself moves | "How is this conversation working, and what keeps it open?" |

## Genuine vs. sincere questions (Ch. 2)

| | **Sincere question** | **Genuine question** |
|---|---|---|
| Test | Meets Searle's felicity conditions | Can't be reduced to a command |
| Logic | An **epistemic imperative**: "Make it so that I know X" | Not about getting information for me |
| Driven by | A deficit (something I lack) | A **surplus** (something worth exploring) |
| Stance | Can be loaded | **Neutral and hospitable** to the answer and the answerer |
| Goal | An answer handed over | **Shared asking**: the question becomes *ours* |
| In dialogue | Interrogation | **Listening with our mouths** |

**Grammar of questions:** open (wh-, "fill in the blank") vs. closed (yes/no, "multiple choice"), tag ("…, right?"), neutral vs. loaded. Grammar alone doesn't make a question open. Openness means **hospitality**.

## Reasoning toolkit (Ch. 4–6)

| Term | Quick definition |
|---|---|
| **Valid** | If the premises are true, the conclusion must be true (a matter of form) |
| **Sound** | Valid + true premises |
| **Strong** | Inductive: true premises make the conclusion probable |
| **Cogent** | Strong + true premises |
| **Abduction** | Inference to the best explanation |
| **Refutation** | Showing an apparent argument is just an exposition |

**Three kinds of truth:** correspondence (sentence matches fact) · constancy (reliable over time) · **alethic** (un-concealment, something "rings true").

**Arguments aren't true or false.** They preserve truth or they don't. **You can't "win" an argument.**

**Logical laws** (non-contradiction, excluded middle) are **constitutive rules**. They make free thinking possible. A contradiction isn't bad thinking, it isn't thinking at all.

**At the edge of reason** ("the unconditioned," Kant), we need **symbols, metaphors, myths, and regulative ideals**. Worldviews built from them have to stay open to revision.

## Pairs people mix up

| This… | …is not this |
|---|---|
| **Dialogue** (open-ended, has an "inner infinity") | **Debate** (adversarial, stops at a winner) |
| **Understanding** (grasping what someone *says*) | **Empathy** (feeling with someone) |
| **Reason** (justification) | **Motive** (psychological cause) |
| **Argument** (supports a conclusion) | **Explanation** (shows *why* something is so) |
| **Use** (endorsing a claim) | **Mention** (reporting a claim) |
| **Prejudice** (pre-judgment, unavoidable, can be put at risk) | **Bias** (an unthinking habit that refuses alternatives) |
| **Worldview** (conscious framework) | **Ideology** (unconscious, misrecognized power structure) |
| **Constitutive rules** (make the activity possible) | **Regulative ideals** (guide and orient it) |
| **Productive negativity** (moves dialogue) | **Nihilating negativity** (stops it) |
| **Lying** (cares about the truth enough to hide it) | **Bullshit** (indifferent to truth; Frankfurt) |
| **Eschatological patience** (dwelling in open questions) | **Apocalyptic impatience** (demanding an end now) |
| **Responsibility as being *in question*** | **Responsibility as answering a "call"** |

## Ten lines to remember

1. Understand a sentence by asking the question it answers.
2. We don't understand questions. We **ask** them.
3. Genuine questions are surplus-driven, neutral, hospitable, and shared.
4. Questioning doesn't erase prejudices. It **puts them at risk**.
5. You can't win an argument. An argument is the unit of reasoning, not a fight.
6. Logical laws are what make free thinking possible.
7. Dialogue never really concludes. It gets interrupted.
8. Genuine questioning is **listening with our mouths**.
9. Thinking is internalized dialogue.
10. The final answer is an evasion of responsibility. Joy lives in ongoing questioning.
